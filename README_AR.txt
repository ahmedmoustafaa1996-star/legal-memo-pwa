منظومة المذكرات القانونية — PWA تجريبي للموبايل والكمبيوتر

الوظائف الحالية:
- إضافة وتعديل وحذف وبحث في القضايا والأحكام والحيثيات.
- تخزين محلي في IndexedDB على نفس المتصفح والجهاز.
- تصدير نسخة احتياطية JSON واستيرادها.
- تشغيل دون إنترنت بعد زيارة الموقع أول مرة واكتمال تخزين الملفات.

النشر من الموبايل على GitHub Pages (باستخدام بيانات تجريبية فقط):
1) افتح github.com وسجل الدخول وأنشئ مستودعًا جديدًا مثل legal-memo-pwa.
2) ارفع محتويات هذا المجلد إلى جذر المستودع (index.html وapp.js وstyle.css وsw.js وmanifest.webmanifest ومجلد icons).
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root) واحفظ.
4) انتظر نشر الموقع، ثم افتح الرابط الذي تعرضه GitHub Pages عبر HTTPS في Chrome على Android.
5) من قائمة Chrome اختر Install app أو Add to Home screen (قد يختلف النص).
6) افتح التطبيق مرة واحدة بالإنترنت، وبعدها جرب وضع الطيران. قد تتأخر أول عملية التخزين قليلًا.

ملاحظة: GitHub Pages استضافة عامة لملفات البرنامج، لا ترفع إليها بيانات قضايا أو أحكام سرية.
البيانات المدخلة في هذه النسخة تظل داخل متصفح جهازك ولا تُرسل إلى GitHub، لكن الحماية المحلية محدودة ولا توجد مصادقة أو تشفير خاص للتخزين.
تجنب إدخال معلومات تحقيقات حقيقية حساسة حتى تطوير الحماية والمزامنة المعتمدة.
مسح بيانات المتصفح أو تغيير الجهاز قد يؤدي إلى فقد السجلات؛ احتفظ بنسخ احتياطية مشفرة في مكان آمن.
لا توجد مزامنة بين الأجهزة حاليًا، ولا تصدير Word أو تحرير مذكرة كاملة بعد.

التطوير المحلي على Windows بعد تثبيت Python:
افتح موجه الأوامر داخل المجلد وشغل: py -m http.server 8000
ثم افتح: http://localhost:8000
لا تعتمد على فتح index.html مباشرة من الملفات لتجربة Service Worker.

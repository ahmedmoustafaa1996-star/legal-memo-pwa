الإصدار 0.2 — محرر المذكرات

1. احتفظ بنسخة احتياطية من البرنامج القديم قبل تحديث الملفات.
2. ارفع محتويات هذا المجلد إلى جذر مستودع legal-memo-pwa مع استبدال الملفات القديمة وإضافة الأيقونات إن كانت ناقصة.
3. لا تحذف بيانات الموقع من Chrome: قاعدة IndexedDB ترقي نفسها من الإصدار 1 إلى 2 وتحتفظ بالقضايا والأحكام والحيثيات.
4. افتح الموقع بعد نشر GitHub Pages، وحدث الصفحة.
5. افتح تبويب المذكرات. يمكنك الحفظ والتعديل وإدراج حيثية من المكتبة.
6. زر Word يصدر ملف DOC تجريبيًا، وليس DOCX مطابقًا لقالبك. تنفيذ مطابقة القالب الأصلي مرحلة تالية منفصلة.
7. كل البيانات محلية على الجهاز. النسخ الاحتياطي يشمل المذكرات الآن ويقبل النسخ القديمة أيضًا.
8. استخدم بيانات تجريبية فقط: GitHub Pages عام، والتخزين المحلي ليس حلًا معتمدًا لأسرار التحقيقات.
